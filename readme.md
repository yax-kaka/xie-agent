# xie-agent 小说写作 CLI v0.9 使用说明

一个跑在终端里的写作搭子:管理人物、场景、世界观、时间线、伏笔;用自然语言指挥 AI 写章。
每章约 3000 字(±500 均可,剧情合理优先)。目录用中文,命令中英双语(如 /model(模型)),
交互对齐 opencode 的 TUI 习惯。

## 快速开始(3 分钟上手)
1. 运行 dist/xie-agent/xie.exe
2. 进入你的小说目录(或任意目录),输入:
      /init(初始化) <作品名>
3. 配置模型(写作前需要 key;管理类操作不需要):
   a. 程序里输入 /model(模型) 一路向导:选提供商/模型 → API Key → 进阶参数
   b. 或设置环境变量 DEEPSEEK_API_KEY=你的key
4. 开始写作:
      /write(写作)          进入写作向导(推荐:逐章配置)
      直接输入文字           AI 写作并自动保存到当前章节;也可以直接说人话让 AI 干别的

## 写作向导(核心用法)
- 输入 /write(写作) 后按提示逐项填写:要写几章 → 每章标题 → 登场人物 → 场景 → 剧情大纲(回车=AI 自动写)
- 人物选择器:↑↓ 移动,空格 选中,回车 确定;输入文字即过滤;
  按 h 隐藏/显示该人物(隐藏后不出现在列表,但输入名字仍可选中);
  按 d 两次删除该人物;选「＋ 新建…」可当场创建(人物默认可见)
- 场景选择器:单选;可选「直接描述新场景(临时,不保存)」或「＋ 新建…」
  新建场景默认隐藏(创建时询问可见性),需要时 /scene(场景) 显示 打开
- 确认后 AI 逐章写作,每章不足 2500 字会自动补写
- 每次保存都会提示文件路径,可直接打开微调

## 命令手册(23 个,中英文均可输入)
写作:
  /write(写作) [指令] [--n 数量] [--from 章号] [--new 标题]
        无参数 = 向导;--n 3 = 一次写 3 章;--from 5 = 从第5章开始;
        ;; 分隔可逐章指定内容;直接输入文字 = AI 写作并保存

设定管理(无参数 = 操作菜单,如 /char(人物) 直接弹出 添加/查看/修改/生成/隐藏/删除 选项;AI 迭代生成,满意才保存):
  /char(人物) 列表|查看|添加 <名> <设定>|生成 <描述>|修改 <名> <意见>|隐藏|显示|删除 <名>
  /scene(场景) 列表|查看|添加 <名> <描述>|生成 <描述>|修改 <名> <意见>|隐藏|显示|删除 <名>
  /world(世界观) 列表|查看|添加 <名> <内容>|生成 <描述>|修改 <名> <意见>|删除 <名>
  /style(风格) 查看|设置 <描述>|提炼 <样章>
  /outline(大纲) 查看|添加 <内容>|添加 第N章 标题:内容
  /time(时间线) 查看|添加 <章> <时间> <事件>|推进 <时间>
  /growth(成长) 查看|添加 <阶段> <描述>
  /vault(伏笔) 列表|添加 <名> [章] [计划]|关闭 <名>
  /idea(灵感) <内容>|列表
  /chapter(章节) 列表|新建 <标题>|定位 <编号>

质量与工具:
  /check(检查) [--deep]   一致性检查(规则引擎;--deep=AI深度校验)
  /reader(读者)           AI 模拟读者反馈(毒点/节奏/断章)
  /summary(摘要) 生成|查看|全部   卷摘要(每10章一卷;防AI遗忘早期剧情)
  /search(搜索) <关键词>   全文检索
  /export(导出) [md|txt]  导出全书
  /stats(统计)             字数统计
  /config(配置) 查看|provider|model|api-key|style|temperature|top-p|reasoning-effort|默认
  /model(模型)             交互式配置:选提供商/模型 → API Key → 进阶参数(temperature/top_p/reasoning_effort) → 测试连接
  /continue(继续)          继续工作(回顾会话+续跑中断的批量写作;等价于 -c)
  /help(帮助) [命令]       帮助(/help(帮助) write(写作) 查看详细用法和示例)
  /quit(退出)              退出

## AI 意图路由(不输命令也能干活)
不输入命令、直接说人话时,AI 会识别意图并调用对应工具,回车确认后执行(缺参时逐个询问补齐):
  帮我新建一个角色          → 新建角色流程
  把林晚改成冷艳型          → 修改角色流程(AI 迭代修改;无 key 时直接重写)
  帮我新建一个场景 青州雪夜  → 场景创建流程
  让主角在城门口遇到敌人    → 写作指令,直接开写
底层是工具调用(参考 opencode):读文件/写文件/列目录 + 人物/场景/世界观/大纲/伏笔等操作;
有 key 时由模型决定调哪个工具,无 key 时回退关键词识别;写作指令始终用你的原话。

## 修改工具(写作中随时调整设定)
- 人物/场景/世界观都有 修改 子命令:/char(人物) 修改 <名字> [修改意见]
  有 key 时读当前档 → AI 基于现有内容+意见迭代修改(满意才保存);
  无 key 时询问新内容直接重写。
- 风格用 /style(风格) 设置;大纲/时间线/成长/伏笔用追加式命令。

## 可见性与删除(互动管理)
- 人物默认可见;场景默认隐藏(创建时可改)
- 隐藏 = 不在候选列表出现,但选择器里输入名字仍可选中(防误操作又不挡人)
- /char(人物) 隐藏/显示、/scene(场景) 隐藏|显示 <名>;选择器内按 h 快速切换
- /char(人物) 删除、/scene(场景) 删除、/world(世界观) 删除(需 y 确认,不可恢复);选择器内按 d 两次删除
- 配置保存在 novel.json 的 picker 字段,不会污染 Markdown 档案

## AI 迭代生成用法(人物/场景/世界观通用)
  /char(人物) 生成 冷面剑客,皇室护卫,为复仇流浪
  → AI 生成草稿(不保存) → 满意输入 y 保存;不满意直接输入修改意见(如 再冷酷一点,话少)继续迭代;n 放弃;q 取消

## 继续工作(-c)
  xie.exe -c 或启动后输入 /continue(继续)
  - 回顾上次会话记录(最近 5 条)
  - 上次批量写作中断时,询问是否从断点继续(不会重复)

## 模型配置
  /model(模型)        交互式配置:模型分组列表 → API Key → 进阶参数
  provider:          /config(配置) provider deepseek(支持 deepseek / openai / ollama / zhipu)
  model:             /config(配置) model deepseek-v4-flash(或 deepseek-v4-pro)
  apiKey:            /config(配置) api-key 或环境变量 <PROVIDER>_API_KEY
  temperature:       novel.json 的 model.temperature(不设置时任务默认:写作 0.9/校验 0.3/读者 0.8;/config(配置) temperature <0-2>)
  top_p:             novel.json 的 model.topP(不设置时不发送,用提供商默认;/config(配置) top-p <0-1>)
  reasoning_effort:  novel.json 的 model.reasoningEffort(不设置时不发送;low/medium/high 控制思考程度,/config(配置) reasoning-effort <low|medium|high|off>)
  maxTokens:         novel.json 的 model.maxTokens(默认8000,足够一章3000字)
  还原默认:           /config(配置) 默认(temperature/top_p/reasoning_effort 恢复默认)

## 字数据则
  目标 3000 字,2500-3500 均为合格(剧情合理优先,非硬规定)
  不足 2500 自动补写(最多 2 轮,补写时若剧情已收束则不硬凑)

## 作品目录结构(全部 Markdown,可直接编辑器修改,改完即时生效)
  novel.json        元数据:模型配置+可见性
  风格.md           写作风格            大纲/总纲.md    总纲+章节大纲
  场景/             持久场景            人物/           人物档案
  世界观/           世界观条目          摘要/           卷摘要 vol1.md…
  时间线.md         时间线              伏笔.md         伏笔台账
  成长.md           主角成长            章节/001.md     章节正文
  笔记/灵感.md      灵感碎片            .会话/          会话记录

  旧版(v0.6 及以前)的英文目录/文件名启动时自动迁移为中文,无需手动处理

## 常见问题
  Q: 没配 key 能写吗? A: 管理类操作可以;写作需要 key,/model(模型) 引导配置,不再静默模拟。
  Q: 写出来的章节在哪? A: 章节/ 目录,保存时都会提示完整路径。
  Q: 换一本书? A: 换目录运行即可,一个目录一部作品。
  Q: AI 忘了早期剧情? A: 每 10 章跑一次 /summary(摘要) 生成

## 终端操作提示
- AI 写作中显示旋转指示器 + 任务文案;按 Esc 一次提示「再按 Esc 打断」,5 秒内再按才真正中断(不保存半截;批量任务保留断点)
- Ctrl+C:按一次提示,3 秒内连按两次才退出(防误触)
- 输入 / 开头时,下方实时显示命令候选列表(纵向,↑↓ 选择,Tab 轮转补全,候选显示 /model(模型) 但补全插入英文 /model)
- 命令后按空格,下方显示该命令用法提示;上下方向键翻看输入历史
- 向导选择器:↑↓ 移动,空格 选择,回车 确定,Esc 取消,输入 过滤,h 隐藏/显示,d 删除(连按确认)
- 激活项用青色加粗、当前项绿色、提示灰色,与历史记录一目了然
