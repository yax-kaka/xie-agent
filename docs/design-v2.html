三、架构(定案)

1
REPL 交互层(轻量)
xie> 提示符;输入 /命令 走命令路由,其他输入 = 写作指令。真实终端逐行交互,管道输入亦可脚本化。
2
命令系统(仿 opencode)
内置命令注册表;后续支持配置自定义命令(模板 + $1/$ARGUMENTS 占位符,opencode command 机制)。
3
上下文组装器
写作请求自动拼装:风格指南(固定层)+ 当前章节 + 最近章节(滚动层)+ 人物档案(按需层);M2 扩展世界观/时间线/伏笔注入。
4
模型层 + 作品库
OpenAI 兼容 chat/completions;novel.json 配置 provider/model,apiKey 走环境变量或配置。作品 = 目录(文件即数据库),零目录外写入。
